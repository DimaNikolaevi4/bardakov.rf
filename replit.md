# Запуск и сборка

Проект использует Eleventy и Node.js 20.

- Установить зависимости: `npm ci`.
- Разработка и предпросмотр: `npm run dev`. Команда собирает сайт и индекс Pagefind, затем запускает Eleventy с отслеживанием изменений на порту 5000.
- Собрать статический сайт: `npm run build`; готовые файлы создаются в `public/`.
- Каталог для статической публикации: `public/`.

Для локальной разработки секреты не требуются.
