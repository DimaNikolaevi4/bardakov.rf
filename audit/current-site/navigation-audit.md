## Проверка вариантов URL и интерфейсных элементов

### Завершающий слэш

Для 42 канонических путей, кроме главной страницы, проверены оба варианта: `/path` и `/path/`.

- все 42 пары вернули HTTP `200`;
- ни один вариант не сделал redirect;
- оба варианта отдают одну и ту же страницу.

Следовательно, trailing slash сейчас не нормализуется: существуют дублирующие варианты URL. Для новой версии нужно выбрать один канонический формат и настроить 301-редирект со второго варианта.

### Варианты с `index.php`

Для всех 43 канонических HTML-путей проверен вариант с префиксом `/index.php`.

- все 43 варианта вернули HTTP `200`;
- redirect на канонический URL не выполняется;
- у проверенных пар совпадает `title`.

Это отдельный класс дублей, который нужно закрыть redirect-правилом или единым каноническим маршрутом при миграции.

### Расширения `.html`, `.php` и URL без расширений

Канонические URL текущего сайта не используют расширения `.html` и `.php`; варианты без расширений работают.

Проверка 10 расширенных вариантов на пяти representative-маршрутах дала:

- 8 вариантов — HTTP `404`;
- 2 варианта — HTTP `301`, но оба ведут не на соответствующую страницу, а на `/abiturientu/professii/15-01-05-svarshchik-ruchnoj-i-chastichno-mekhanizirovannoj-svarki-naplavki?layout=blog`.

Последнее поведение следует считать некорректным fallback/redirect и отдельно проверить перед миграцией.

### Страница 404

Для несуществующего URL production возвращает HTTP `404`.

- заголовок страницы: `404 Страница не найдена`;
- подключены отдельные error-стили Gantry/Elixir;
- в `<body>` присутствует класс `g-error`;
- отображается понятный текст: «Извините, такой страницы у нас нет. Но есть много другой полезной информации.»;
- на странице присутствуют главное меню, footer и мобильный offcanvas-контейнер;
- отдельный `<h1>` в HTML не найден — это небольшое замечание по семантике.

### Хлебные крошки

Breadcrumb-разметка не обнаружена на главной странице, странице раздела, странице статьи для родителей и глубокой учебной странице: отсутствуют `breadcrumb` и `g-breadcrumb` в HTML.

Вывод: текущая версия сайта хлебные крошки не использует. Для новой версии их стоит добавить на страницах глубже первого уровня, особенно в разделах «Обучение» и «Абитуриенту».

### Мобильное меню

В HTML есть необходимые элементы Gantry offcanvas:

- контейнер `#g-offcanvas`;
- `#g-mobilemenu-container`;
- переключатель `.g-offcanvas-toggle` с `aria-controls="g-offcanvas"` и `aria-expanded="false"`;
- breakpoint мобильного меню `51rem`.

Структура подключения мобильного меню подтверждена, но интерактивное открытие и закрытие в реальном браузере этим проходом не выполнялось. Пункт остаётся частично проверенным до браузерного теста.
