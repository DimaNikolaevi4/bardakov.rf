---
name: Husky при установке зависимостей
description: Как восстановить npm-зависимости, если Git hook блокирует установку в Replit.
---

Если `npm ci` завершается ошибкой на `prepare`-скрипте Husky, который пытается менять `.git`, повторите установку с `HUSKY=0 npm ci`. Это отключает только установку хуков, оставляя зависимости из lockfile нетронутыми.

**Why:** Среда Replit защищает служебную Git-конфигурацию, поэтому Husky не может безопасно менять её при импорте проекта.

**How to apply:** При таком отказе не разрешайте изменение `.git`; повторите установку с `HUSKY=0`.
