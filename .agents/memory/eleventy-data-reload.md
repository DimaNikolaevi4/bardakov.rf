---
name: Перезагрузка данных Eleventy
description: Обновление YAML-данных сайта, которые загружаются через JavaScript-модули Eleventy.
---

В режиме Eleventy `--watch` изменение YAML-файла может пересобрать страницы, но оставить в уже импортированном JavaScript-модуле старые значения из этого YAML. После изменения таких данных перезапускайте workflow приложения, чтобы модуль загрузил актуальные значения.

**Why:** При перестановке разделов сгенерированная разметка продолжала показывать прежний порядок после watch-сборки, хотя исходный YAML и время файла сборки уже обновились.

**How to apply:** После правок YAML, который читается соседним JS-модулем данных, перезапустить workflow и проверить порядок в сгенерированном HTML.
