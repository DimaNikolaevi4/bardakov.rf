## 💡 Краткий вывод по структуре

Сайт имеет классическую, логичную и **плоскую иерархию** (глубина вложенности не превышает 3 уровней), что характерно для персональных сайтов-портфолио педагогов.

**Основные разделы чётко разделены по целевой аудитории:**
1. **Общая информация** → Обо мне
2. **Учебный процесс** → Обучение, Воспитание
3. **Помощь поступающим** → Абитуриенту
4. **Связь** → Контакты

**Рекомендации для миграции:**
- Сохранить ту же 5-секционную структуру в новом проекте на Eleventy
- Сохранить плоскую иерархию (не более 3 уровней вложенности)
- Все 12 гос-ссылок вынести в footer (уже сделано в `src/_data/navigation.json`)
- Раздел «Контакты» реализовать через Formspree (внешний сервис) — `src/_includes/components/contact-form.njk`
- 30+ PDF «Разговоры о важном» хранить на хостинге Beget (тяжёлые — через symlink в `~/bardakov.rf-v2/large-media/`)
