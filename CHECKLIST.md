# Чек-лист: Создание копии сайта бардаков.рф на Joomla 5 для совместной работы через GitHub

## Цель

Создать полную копию сайта https://бардаков.рф/ на Joomla 5 в репозитории GitHub (аналогично https://github.com/DimaNikolaevi4/site), чтобы обеспечить совместную работу над сайтом через Git.

---

## Этап 1. Подготовка

- [ ] Убедиться в наличии полного доступа к администраторской панели Joomla (бардаков.рф)
- [ ] Убедиться в наличии доступа к хостингу (FTP / файловый менеджер / SSH)
- [ ] Убедиться в наличии доступа к базе данных (phpMyAdmin или консоль)
- [ ] Проверить версию Joomla (должна быть Joomla 5.x)
- [ ] Записать текущие версии: PHP, MySQL/MariaDB, веб-сервер
- [ ] Создать приватный репозиторий на GitHub (если ещё не создан)

## Этап 2. Копирование файлов сайта

- [ ] Подключиться к хостингу через FTP (FileZilla) или файловый менеджер панели хостинга
- [ ] Скачать все файлы сайта в локальную директорию проекта
- [ ] Проверить целостность скачанных файлов (сравнить количество файлов и размеры ключевых директорий)
- [ ] Убедиться, что скрытые файлы (например, `.htaccess`) также скачаны

## Этап 3. Настройка .gitignore

- [ ] Создать файл `.gitignore` в корне проекта со следующими исключениями:

```gitignore
# Конфигурация (содержит пароли и секреты)
configuration.php

# Временные файлы и кэш
cache/
tmp/
logs/

# Системные файлы
.DS_Store
Thumbs.db

# IDE и редакторы
.idea/
.vscode/
*.swp
*.swo

# Бэкапы
*.sql
*.sql.gz
*.sql.bz2
```

- [ ] Создать файл `configuration.php.example` — шаблон конфигурации с плейсхолдерами:

```php
<?php
class JConfig {
    public $host = 'localhost';
    public $user = 'db_user';
    public $password = 'db_password';
    public $db = 'db_name';
    public $dbprefix = 'jos_';
    public $secret = 'your_secret_key';
    public $log_path = '/tmp';
    public $tmp_path = '/tmp';
    // ... остальные параметры
}
```

- [ ] Добавить в `.gitignore` дамп БД (`*.sql`, `*.sql.gz`), если он будет храниться рядом

## Этап 4. Инициализация Git-репозитория

- [ ] Открыть терминал в корне проекта
- [ ] Выполнить `git init`
- [ ] Выполнить `git add .`
- [ ] Выполнить `git commit -m "Начальная выгрузка файлов сайта бардаков.рф"`
- [ ] Добавить удалённый репозиторий: `git remote add origin https://github.com/DimaNikolaevi4/bardakov.rf.git`
- [ ] Выполнить `git push -u origin main`

## Этап 5. Работа с базой данных

- [ ] Зайти в phpMyAdmin на хостинге
- [ ] Выбрать базу данных сайта
- [ ] Экспортировать базу в SQL-формате:
  - Метод экспорта: Обычный
  - Формат: SQL
  - Кодировка: utf8mb4
  - Поставить галочку «Добавить DROP TABLE / VIEW / PROCEDURE»
  - Поставить галочку «Добавить CREATE TABLE»
- [ ] Сохранить дамп в файл (например, `database/dump.sql`)
- [ ] Проверить размер дампа и его работоспособность (попробовать импортировать на локальной машине)

## Этап 6. Локальное развёртывание (для каждого разработчика)

- [ ] Установить локальный веб-сервер (XAMPP / Docker / LAMP)
- [ ] Клонировать репозиторий: `git clone https://github.com/DimaNikolaevi4/bardakov.rf.git`
- [ ] Создать локальную базу данных MySQL
- [ ] Импортировать дамп БД: `mysql -u root -p db_name < database/dump.sql`
- [ ] Скопировать `configuration.php.example` в `configuration.php` и заполнить локальными данными
- [ ] Убедиться, что сайт открывается по локальному адресу

## Этап 7. Организация совместной работы

- [ ] Создать ветку `develop` для основной разработки: `git checkout -b develop`
- [ ] Договориться о правилах коммитов (формат сообщений, именование веток)
- [ ] Договориться о процессе обновления дампа БД (кто и когда обновляет)
- [ ] Настроить защиту ветки `main` (запрет прямых коммитов, только через Pull Request)

---

## Примечания

- Файл `configuration.php` **никогда** не должен попадать в репозиторий — он содержит пароли и секреты
- Дамп БД обновляется вручную при значительных изменениях структуры или контента
- Для обновления дампа рекомендуется создавать отдельную ветку и Pull Request
- Ссылка на аналогичный репозиторий: https://github.com/DimaNikolaevi4/site
