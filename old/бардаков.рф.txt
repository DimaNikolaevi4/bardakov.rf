Идея:
Создать копию (на подобии как в https://github.com/DimaNikolaevi4/site) сайта https://бардаков.рф/ на Joomla 5 (администратор имею все доступы) для совместной работы через GitHub.
Для этого файлы движка выгружаются в один репозиторий, а дамп базы данных используется
для создания копии сайта.

Пункт 1. Копирование файлов Joomla:
- Скачать все файлы сайта с хостинга (через FTP или файловый менеджер).
- Создать .gitignore, исключив configuration.php, папки cache, tmp, logs и другие секретные данные.
- Инициализировать Git-репозиторий, сделать первый коммит и загрузить в приватный репозиторий на GitHub.

Пункт 2. Работа с базой данных:
- Сделать дамп базы данных Joomla через phpMyAdmin (экспорт в SQL-формате).
