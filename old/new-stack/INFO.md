# Информационный файл: Создание сайта бардаков.рф на простом HTML-стеке

## 1. Утверждённый стек

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Разметка | **HTML5** | Страницы сайта — чистый HTML, без шаблонизатора |
| Стили | **Bootstrap 5.3** (CDN) | Адаптивная сетка, компоненты, иконки |
| Кастомный CSS | **style.css** (1 файл) | Цвета, шрифты, отступы, свои стили |
| Скрипты | **main.js** (1 файл) | JS-include шапки/подвала, меню, доступность |
| Поиск | **Pagefind** | Статический поиск — индексирует HTML, работает без сервера |
| Шапка/подвал | **JS-include** | Общий header.html / footer.html подключаются через fetch() |
| Версионирование | **Git** | Все файлы в репозитории GitHub |
| Хостинг | **Beget** (или любой) | Статические HTML-файлы — не нужен PHP/Node.js |

**Не используется:** Eleventy, Nunjucks, Lunr.js, Decap CMS, Node.js, сборка, npm.

## 2. Почему простой HTML, а не Eleventy

| Критерий | Простой HTML | Eleventy (как у СИТ) |
|----------|-------------|----------------------|
| Страниц на сайте | ~25 | — |
| Обновления | Раз в полгода | — |
| Файлов для проекта | ~30 | ~60+ |
| Порог входа | Открыл HTML — редактируешь | Node.js, npm, шаблоны, сборка |
| Добавить страницу | Скопировал template, поменял текст | Создать .md + front matter, запустить сборку |
| Хостинг | Любой, даже без SSH | Нужна сборка на сервере |
| Зависимости | 0 (Bootstrap с CDN) | 15+ npm-пакетов |
| Время на проект | 2-3 дня | 1-2 недели |

Для сайта с 25 страницами и редкими обновлениями — HTML оптимально.

## 3. Поиск — Pagefind

**Pagefind** (https://pagefind.app) — это инструмент статического поиска, созданный специально для HTML-сайтов:

- После размещения HTML-файлов запускается `npx pagefind --site .` — создаётся папка `pagefind/` с индексом
- На страницу `/search/` подключается `pagefind.js` и виджет `PagefindUI`
- Поиск работает мгновенно, без сервера, без API
- Поддержка русского языка из коробки
- Вес индекса: ~50-100 КБ для 25 страниц

**Как использовать:**
1. Добавить `data-pagefind-body` к `<main>` на каждой странице (индексируется только этот контент)
2. После изменений запустить: `npx pagefind --site .` (в корне сайта)
3. Папка `pagefind/` добавлена в `.gitignore` — не коммитится

## 4. JS-include для шапки и подвала

Общий header и footer хранятся в `/assets/components/header.html` и `/assets/components/footer.html`. На каждой странице стоят плейсхолдеры:
```html
<div id="header-placeholder"></div>
<!-- ...контент... -->
<div id="footer-placeholder"></div>
```

Скрипт `main.js` загружает компоненты через `fetch()` и вставляет в плейсхолдеры. Подсветка текущего пункта меню — автоматическая по URL.

**Важно:** для работы JS-include сайт должен открываться через веб-сервер (не `file://`). На хостинге это работает автоматически.

## 6. Как добавить новую страницу

1. Скопировать `assets/components/page-template.html` в нужную папку
2. Заменить `ЗАМЕНИТЬ_ЗАГОЛОВОК`, `ЗАМЕНИТЬ_ОПИСАНИЕ`, `ЗАМЕНИТЬ_РАЗДЕЛ`
3. Заполнить контент внутри `<main data-pagefind-body>`
4. Обновить хлебные крошки
5. При необходимости — добавить ссылку в `header.html`
6. Запустить `npx pagefind --site .` для обновления индекса поиска
7. Закоммитить в Git

## 7. Доступность

Реализована простая «Версия для слабовидящих» — кнопка A+ в шапке:
- Переключает высокую контрастность (чёрный фон, жёлтый текст)
- Увеличивает размер шрифта
- Настройка сохраняется в `localStorage`

При необходимости можно расширить (линейка для чтения, озвучка текста).

## 8. Миграция с Joomla

### Что переносим:
- Текст статей → HTML (вручную или конвертацией из дампа БД)
- Изображения → `/assets/images/`
- PDF/DOC вложения → `/assets/docs/`
- Структура меню → `header.html`

### Что НЕ переносим:
- Пользовательские аккаунты Joomla
- Модули и плагины Joomla
- Компоненты Joomla (поиск, формы)
- `configuration.php` и БД

### URL-миграция:
- Старые URL Joomla (`/index.php/obo-mne/dostizheniya`) → 301-редирект на новые (`/obo-mne/dostizheniya.html`) через `.htaccess`
