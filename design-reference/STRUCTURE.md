## 📐 Виды страниц (Шаблоны / Layouts)

Все страницы наследуются от базового каркаса, но имеют свои специфические надстройки.

| Тип страницы | Файл шаблона | Назначение и особенности |
|---|---|---|
| **Базовый каркас** | `layouts/base.njk` | Обёртка для всех страниц. Содержит `<head>` (SEO, Open Graph, JSON-LD Person schema, защита от FOUC), подключение стилей, 7 блоков страницы и скрипты. |
| **Главная** | `layouts/index.njk` | Лендинг. Hero + цитата + 4 карточки разделов + краткие контакты. |
| **Раздел / Подраздел** | `layouts/section.njk` | Страница категории (например, `/obuchenie/`). Hero раздела + хлебные крошки + вводный текст + сетка карточек подразделов. |
| **Материал / Статья** | `layouts/article.njk` | Страница конкретного контента (например, практическая работа или статья). Содержит: хлебные крошки, заголовок, мета-данные (дата, автор), основной текст из Markdown и блок для скачивания документов (badge.njk или список ссылок). |
| **Контакты** | `layouts/kontakty.njk` | Карта, реквизиты, режим работы и встроенная форма обратной связи (contact-form.njk с защитой honeypot). |
| **Поиск** | `layouts/search.njk` | Страница с результатами работы Pagefind. Интегрируется с search-modal.njk. |
| **Ошибка 404** | `layouts/404.njk` | Страница "Не найдено" с сохранением глобального меню и предложением перейти на главную. |

## 🧱 7 блоков страницы

Каждая страница состоит из 7 блоков. Блоки 1 и 7 — глобальные (из `base.njk`), блоки 2-6 переопределяются в каждом layout.

| # | Блок | Где определяется | Содержимое |
|---|---|---|---|
| 1 | **Меню** | `base.njk` → `header.njk` | Логотип, навигация, иконки (email/search/a11y/theme), бургер |
| 2 | **Витрина** (hero) | В каждом layout (свой) | Заголовок раздела/страницы + подзаголовок + описание |
| 3 | **Хлебные крошки** | В каждом layout (через `breadcrumb.njk`) | Путь к текущей странице (schema.org BreadcrumbList) |
| 4 | **Верхний блок тела** | В каждом layout (свой) | Вводный текст (section) / мета-данные (article) / контактная инфа (kontakty) |
| 5 | **Средний блок тела** | В каждом layout (свой) | Сетка карточек (section) / основной контент (article) / форма (kontakty) |
| 6 | **Нижний блок тела** | В каждом layout (свой) | Доп. информация / документы для скачивания / теги / related / CTA |
| 7 | **Подвал** | `base.njk` → `footer.njk` | 3 колонки (бренд + навигация + контакты) + 12 гос-ссылок + копирайт |

## 📊 Схема наследования

```
base.njk (Базовый каркас)
├── <head> (SEO, FOUC, стили)
├── Блок 1: header.njk (меню)
├── Блоки 2-6: {% block content %} ← переопределяется
│   ├── index.njk     (Главная: hero + цитата + карточки + контакты)
│   ├── section.njk   (Раздел: hero + breadcrumb + intro + cards + extra)
│   ├── article.njk   (Статья: breadcrumb + header + meta + body + footer)
│   ├── kontakty.njk  (Контакты: hero + breadcrumb + info + form + CTA)
│   ├── search.njk    (Поиск: hero + pagefind UI)
│   └── 404.njk       (404: hero + ссылки)
└── Блок 7: footer.njk (подвал)
```
